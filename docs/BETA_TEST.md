# Closed beta script

This script is for 5–10 presenters using teaching, Lightning Talk and product-demo scenarios. Each presenter should use a new project and report the browser, presentation tool, audience size and network environment.

## Presenter tasks

1. Enter with Google OAuth or a Guest Vault and create one project from a template.
2. Edit at least one cue and add understanding, single-choice, word-cloud and Q&A interactions.
3. Preview projection, mobile audience and presenter-remote surfaces.
4. Open a live room, join from a second device and complete every interaction type.
5. Moderate a Q&A item by voting, pinning, answering and hiding it.
6. Use the phone remote and transparent OBS link.
7. For Google Slides, install and pair the extension, map at least three slides, move forward and backward, switch to manual, simulate a disconnect, and confirm resync.
8. Export CSV, open diagnostics, and verify account deletion wording without confirming deletion unless using a disposable account.

## Acceptance questions

- Did any interaction require verbal explanation before the audience could use it?
- Did automatic slide following ever select the wrong cue or change state after manual takeover?
- Was the understanding signal fast and clear enough to affect the presentation?
- Did any Chinese or English label feel ambiguous, truncated or inconsistent?
- Could all controls be reached and understood with keyboard navigation and 200% browser zoom?
- What would prevent using Slideact in a real presentation next week?

## Exit criteria

- 5–10 completed presenter sessions with scenario and environment recorded.
- No unresolved data-loss, cross-account access, wrong-slide, or unrecoverable live-session issue.
- At least 80% of presenters can create, launch and close a room without assistance.
- Google Slides compatibility matrix updated with each exercised browser/version.
- Findings triaged into must-fix, follow-up and product-idea categories.

This repository cannot truthfully mark the human beta complete until those sessions occur. Automated CI, the 100-person synthetic benchmark and browser semantic acceptance are prerequisites, not substitutes.
